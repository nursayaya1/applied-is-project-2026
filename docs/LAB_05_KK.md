# Зертханалық жұмыс 5 — Streamlit интерфейсі

Мақсат: пайдаланушы API сұраныстарын қолмен жазбай, браузердегі формалар арқылы жұмыс істеуі керек. Код `frontend/app.py` ішінде.

## Не жасалды

- Бүйірлік панель, төрт бөлім және жазба сандары.
- Мәліметтер SQLite-дан тікелей емес, FastAPI-ге HTTP сұранысы арқылы алынады.
- Иелер, жануарлар, ветеринарлар және қабылдаулар үшін іздеу өрістері бар. Жануарлар түрі мен жас аралығы бойынша сүзіледі.
- Формалар POST JSON жібереді. Қосу сәтті болса, жасыл хабарлама мен жаңартылған тізім көрсетіледі.
- Әр бөлімде «Жазбаны жою» ашылады. Жазбаны таңдап, растау белгісін қойғаннан кейін DELETE жіберіледі. Байланысты жазбалары бар нысанды сервер қорғайды.
- Сервер өшсе, бетте бір түсінікті хабарлама шығады. HTTP 204 жауабын JSON ретінде оқуға әрекет жасалмайды.

## Іске қосу

Бірінші терминал:

```powershell
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Екінші терминал:

```powershell
.\venv\Scripts\python.exe -m streamlit run frontend/app.py
```

http://localhost:8501 ашыңыз. «Жануарлар» бөлімінде іздеу мәтінін енгізіп Enter басыңыз немесе өрістен шығыңыз: Streamlit скриптті қайта орындап, query параметрлерімен жаңартылған тізімді алады. Бұл әр перне басылған сайын емес, мәтіндік өрістегі өзгеріс бекітілгенде орындалады.

## Қолмен тексеру

1. «Иелері» бөлімінде «Сынақ иесі» және оқу телефонын енгізіп қосыңыз. Жасыл хабарлама мен жаңа жол шығуы тиіс.
2. Іздеу өрісіне «Сынақ» енгізіңіз. Тек сәйкес жолдар қалады.
3. «Жазбаны жою» бөлімінен жаңа иесін таңдаңыз. Растау белгісін қойып «Жою» басыңыз. Жол жоғалады.
4. «Жануарлар» бөлімінде «марға» іздеп, түрі мен жас сүзгісін өзгертіңіз.
5. Қабылдауы бар жануарды жоюға әрекет жасасаңыз, сервер қайшылық хабарламасын береді; жазба сақталады.

## Қорғау жауаптары

Streamlit пен FastAPI HTTP арқылы JSON алмасады. `params` URL-дегі query параметрлерін, `json` сұраныс денесін береді. Форма → requests → FastAPI → SQLModel Session → SQLite → JSON жауап → жаңарған кесте.

Streamlit виджет өзгергенде скриптті қайта орындайды. `st.form` ішіндегі өзгерістер жіберу батырмасына дейін жиналады. `st.session_state` сәтті операция хабарламасын келесі орындалуға сақтайды.

Артықшылығы — Python арқылы тез интерфейс құру. Шектеуі — күрделі дизайн мен браузерлік әрекеттерді басқару классикалық frontend-ке қарағанда аз икемді.

ИИ промпті: «Ветеринарлық клиника Streamlit интерфейсіне API query іздеуін, POST формасын, DELETE растауын және сервер өшкендегі қате өңдеуді қос. Жеке базаға тікелей қосылма».
